The script that rebuilds the album every 15 minutes — pulls new photos from Drive, bakes in reaction counts and voter names.

The album's visual styling, read by the script above.

Backup copy of the Google Apps Script code. The live version runs inside the "Album Reactions" Google Sheet.

The automation that runs the 15-minute refresh.
